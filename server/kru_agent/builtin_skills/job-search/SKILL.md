# Пошук вакансій

## 1. Профіль (щоразу на початку)

Прочитай `робота/профіль.md`. Якщо його немає — спитай одним повідомленням і збережи (write_file):
- посади й рівень (напр. AI/LLM engineer, Python developer, cybersecurity analyst; junior/middle);
- стек і сильні сторони (і кейси — напр. «власний локальний AI-агент Кру»);
- формат і місто (віддалено / Житомир / Київ / за кордон), тип (повна, part-time, контракт, фриланс);
- зарплата від (і валюта), мови (українська, англійська — рівень);
- сайти, на яких шукати, і що НЕ пропонувати (компанії, сфери, ключові слова-виключення).
Користувач змінює профіль словами («додай Rust», «шукай і в Польщі») — онови файл.

## 2. Пошук

1. Для кожної посади з профілю — кілька запитів web_search (за потреби з site:): djinni.co, jobs.dou.ua,
   work.ua, robota.ua, linkedin.com/jobs, а також сайти з профілю; англійською й українською. Свіжість —
   за останні 1–3 дні, якщо пошук щоденний.
2. Відкрий найперспективніші (fetch_url), щоб узяти справжні вимоги, зарплату, формат — не вгадуй зі сніпета.
3. Відкинь: не відповідає профілю, виключення, застарілі (закриті, старші за 30 днів), дублікати (та сама
   вакансія на кількох сайтах — лишай одну, із найкращим посиланням).
4. **Лише нові:** прочитай `робота/бачені.md` (посилання й «компанія — посада» вже показаних) і не повторюй їх;
   нові допиши туди (write_file, append=true) з датою.

## 3. Звіт

Відсортуй за відповідністю профілю. Для кожної (до 10):
**Посада — Компанія** · формат/місто · зарплата (якщо вказана)
відповідність: висока / середня — чому одним рядком (що збігається, чого бракує)
посилання

Наприкінці одним рядком: скільки переглянуто, скільки нових, порада (напр. «на 2 вакансії варто відгукнутися
сьогодні — свіжі й під твій стек»). Нових немає — так і скажи коротко, без вигаданих вакансій.
У Telegram (send_telegram чи завдання за розкладом) — той самий формат, коротко.

## 4. Щодня

Якщо є (або користувач хоче) щоденне завдання — його текст: «Використай навичку job-search: знайди нові
вакансії за профілем за останню добу й надішли звіт у Telegram». Наявне завдання про вакансії
(list_scheduled) можна замінити таким — спершу спитай.

## 5. Допомога з відгуком

Якщо користувач хоче відгукнутися: прочитай вакансію, коротко — чому підходить і чого бракує, і склади
супровідний лист (3–6 речень, конкретно під вимоги, з його кейсом; без загальних фраз). Мова — як у вакансії.
