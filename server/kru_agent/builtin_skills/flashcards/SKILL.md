# Картки з інтервальним повторенням

Картки й розклад зберігають інструменти flashcards_* (колоди — `навчання/картки/<колода>.json`).
Дати рахують вони — ти лише складаєш картки, питаєш і оцінюєш.

## Зробити картки з матеріалу

1. Визнач колоду: одне слово латиницею за темою (`nist-csp`, `english`, `networking`). Якщо до теми є
   навичка (напр. nist-csp-exam з конспектом) — бери матеріал звідти.
2. Одна картка — один факт. Питання коротке й однозначне, відповідь стисла:
   - термін → визначення («Що таке Target Profile у CSF 2.0?»);
   - визначення → термін («Функція CSF, що встановлює стратегію й політику ризиків?» → Govern);
   - перелік → питання на весь перелік, але короткий («6 функцій CSF 2.0?»);
   - ситуація → застосування («Компанія інвентаризує ноутбуки — яка категорія?» → ID.AM).
   Не роби карток «так/ні» і з кількома фактами в одній.
3. 10–30 карток за раз — `flashcards_add`. Покажи користувачу список питань (без відповідей) і скільки додано.

## Повторення

1. `flashcards_due` (без deck — з усіх колод). Нема що повторювати — скажи, і запропонуй додати нові.
2. Питай ПО ОДНІЙ картці: лише питання. Відповідь не показуй, доки користувач не відповість.
3. Оціни по суті (синоніми й інші слова — ок, головне зміст): `flashcards_grade` з correct=true/false.
   Скажи коротко «✓» або «✗ правильно: …» з поясненням в одне речення.
4. Голосом (режим «Кру»): так само по одній, коротко, без розмітки.
5. Наприкінці — `flashcards_stats`: скільки повторено, правильно, що лишилось, які найважчі.

## Щодня

Якщо користувач хоче щоденне повторення — запропонуй schedule_task (repeat=daily, у зручний час) із
завданням: «Використай навичку flashcards: надішли в Telegram, скільки карток на сьогодні, і перші 5 питань
(без відповідей)». Відповіді він дасть, коли відкриє чат.
